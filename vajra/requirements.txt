# manylinux_2_28_x86_64. On older hosts (Amazon Linux 2 is glibc 2.26) pip finds no
# compatible wheel, falls back to an sdist, and fails on the system GCC. Do not install
# this file directly there -- run `make venv`, which delegates to scripts/setup_env.sh and
# sources the compiled packages from conda-forge (glibc 2.17 builds) at the same versions.
